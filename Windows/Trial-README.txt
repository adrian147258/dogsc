DogSC Windows Beta 2 · 录制优化、屏幕 3D 与暂停录制

这是根据神烦老狗的 DogSC 二次创作的非官方 Windows 版本，当前还不完善。
原作：https://github.com/laogou717/dogsc
Windows 源码：https://github.com/adrian147258/dogsc
原作与改编源码采用 MIT，保留原作者版权；FFmpeg 和字体遵循各自许可。

使用方法
1. 将整个 ZIP 解压到一个可写文件夹（例如桌面），不要直接在压缩包内运行。
2. 双击 Windows/bin/DogSC.Windows.exe；也可双击 Start-DogSC.cmd。
3. 保留整个文件夹结构，不要只移动 EXE。

运行环境：Windows 10/11 64 位、.NET Framework 4.8。
录屏组件已包含，不需要另外下载或安装 FFmpeg。

这次新增
- 录制流畅性：录制前停止编辑器播放、预览、缩略图与波形任务，并收起编辑器；鼠标使用独立高精度采样，界面卡住时继续采集；压缩静止轨迹，优化编码并行队列和显卡回退，减少 CPU 与诊断负担。保留原始尺寸、所选帧率及暂停保存。
- 弹窗与交互：原版圆角确认卡片，重命名回车 / Esc，菜单快捷键和当前选项；自定义饱和度 / 亮度 / 色相 / HEX 调色面板，实时预览、整次撤销，关闭保留当前颜色；导出取消后可重试，完成后的打开文件夹不再关闭窗口。
- 右侧设置面板：固定画面页签、范围标签、布局紧凑位置板、普通参数上下式滑杆、滚动位置记忆、颜色输入胶囊与高级参数折叠。
- 视觉收尾：原版风格的位置与倾斜控制板、精确角度读数、按原版分页面排列参数、选中态、明暗外观、暂停继续按钮与小窗口侧栏；修复屏幕 3D 页签无法点击。
- 修复录制保存流程：分段 MP4、合并重复停止请求、保存后校验；失败保留原始素材和诊断。
- 精细界面：背景缩略图与选中标记、壁纸/图案/自定义分类、场景预设图卡、光标预览、颜色胶囊、贴图素材列表、原版顺序参数分组、细滚动条。
- 编辑器、录制浮条与导出窗口使用统一圆角和控件样式；基础音频波形。
- 光标：新录制的光标与画面分开保存，可换形态、调大小、隐藏、平滑、静止隐藏、时间校准与摆动；四种点击反馈。
- 贴图：导入透明 PNG 或 JPG，拖动、缩放、旋转，调整透明度、层级、圆角、描边和阴影；进入/退出动画、背景虚化、隐藏录屏。
- 柔化：局部模糊或突出区域；位置、大小、圆角、强度、出现时间与过渡；随录屏缩放移动。
- 贴图与柔化各有时间线轨道，可拖动整段或两端；多层贴图可上下滚动查看。
- 效果支持撤销/重做、项目保存和视频导出；图片嵌入项目，删除外部图片后仍能重开。

注意：旧录制及导入视频里的光标已成为画面像素，无法无损替换/隐藏。请使用本版重新录制。
新录制的 source.mp4 不含光标。观看完整光标和背景效果，请通过编辑器预览或导出成片。

录制与保存
- 停止录制后自动保存原始视频和编辑项目，不需要另点保存才能保留原素材。
- 新项目与鼠标轨迹先保存，再切换到编辑器；取消切换时原项目修改保留，新录制也保存在录制目录。
- 文件位于本文件夹的 Windows/recordings/日期时间/。
- source.mp4 为原始视频，project.dogscwin 为编辑项目；保留原视频才能重开项目。
- 修改项目后按 Ctrl+S 保存；带光标、贴图、背景、缩放等效果的成品需要点击“导出”。
- 屏幕 3D：运镜页添加独立片段，调倾斜、旋转、透视、位置与大小；进入和返回过渡，支持分割、拖动、撤销与导出。
- 录制暂停：录制中点暂停/继续；暂停时不采集画面、麦克风和鼠标，计时冻结。可在暂停状态直接停止保存。分段作为恢复素材保留于 segments/。
- 本版包含屏幕 3D、录制暂停、设置面板与弹窗交互改进，以及录制流畅性优化。
- 帧率可选 30/60/90 FPS。探测 NVIDIA/AMD/Intel 编码器，不支持时回退；Intel 硬件路径仍需对应设备验证，实际流畅度因设备而异。
- 原始视频每 0.5 秒提交一个片段，异常中断后通常可读取已提交素材，尚未写完的尾段可能丢失。

备忘录
- 从录制浮条右侧便笺按钮或项目菜单打开。
- 文稿和设置保存到当前用户的 %LOCALAPPDATA%/DogSC.Windows/。
- 体验包不包含发送者的录屏、项目、备忘录或个人设置。

这是根据 DogSC 开源项目适配的 Windows 开发体验版，并非原作者官方发行版。
光标使用 Windows 矢量形状，部分手形与原版有差异；模糊、阴影和光晕采用 Windows 绘制。
相邻贴图的复杂衔接、摄像头联动尚未完成。摄像头、系统声音、录制标记等仍未移植。
完整功能及已知差异见 Windows/README.md。
遇到问题，可提供录制目录中的 capture-backend.txt、capture-performance.txt；启动错误在 Windows/bin/last-error.txt。
